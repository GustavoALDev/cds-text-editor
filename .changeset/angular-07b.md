Diretivas de validação de texto para Template e Reactive Forms no entry `/validators` (spec 07b): `RteRequiredValidator` (`rteRequired`), `RteMaxCharsValidator` (`[rteMaxChars]`), `RteMaxWordsValidator` (`[rteMaxWords]`), `RteSafeLinksValidator` (`rteSafeLinks`) e `RteNoEmptyHeadingsValidator` (`rteNoEmptyHeadings`), no padrão das diretivas de envio (`addValidators`/`removeValidators` no controle do elemento, sem `NG_VALIDATORS`). README com os caminhos de CSS pelos especificadores dos `exports`.
