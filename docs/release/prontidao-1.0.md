# Prontidão para a 1.0

Lista de pré-condições da `1.0.0` (spec 09c, AP14; [ADR 0023](../decisions/0023-api-estavel-e-prontidao.md)). A regra `checkProntidao` do `npm run check:rules` confere a tabela: `Dono` é `agente` ou `dono`; `Estado` é `feito` ou `aberto`; linha `feito` tem `Evidência`; linha do `dono` em aberto tem `TODO-AUTOR`.

A `1.0.0` só sai com **todas** as linhas `feito` (`RTE_ALLOW_1_0=1` no PR da 1.0, spec 09b). O agente não decide nem executa nada da coluna `dono`: publicação, nome, consumidor real, leitores de tela e proteção de branch são do autor.

Evidências citam commits da branch `feat/spec-09c` (hashes curtos), ADRs e specs.
