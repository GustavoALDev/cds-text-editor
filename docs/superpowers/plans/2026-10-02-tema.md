## Global Constraints

- Pacote `@cds/rte-theme` **sem Angular** e **sem build de tema**; sem dependência de nenhum pacote do repo; `sideEffects` declara só o CSS (`["*.css"]`); o JS é tree-shakeable.
- **R1** Variáveis públicas e estáveis: nível 1 `--rte-primary/secondary/tertiary`; nível 2 `--rte-radius`, `--rte-density`, `--rte-font-sans`, `--rte-font-mono`, `--rte-font-size`, `--rte-line-height`; nível 3 `--rte-surface`, `--rte-surface-raised`, `--rte-text`, `--rte-text-muted`, `--rte-border`, `--rte-focus`, `--rte-danger`, `--rte-warning`, `--rte-success`, `--rte-code-*`; derivadas `--rte-<cor>-hover/-active/-subtle/-border/-text` e `--rte-on-<cor>`; internas `--_*` nunca documentadas.
- **R2** Contraste mínimo para **qualquer** cor válida, em claro e escuro: texto sobre a cor ≥ 4,5 (normal, hover, active); `*-text` ≥ 4,5 sobre superfície, superfície elevada e fundo suave; foco ≥ 3; texto neutro ≥ 7; texto secundário ≥ 4,5.
- **R3** Valor inválido (`banana`, vazio, `var(--inexistente)`, `12px`) cai no padrão Angular (`@property`).
- **R4** Prioridade: padrão < `:root` < ancestral < instância (inline). Todo o CSS em `@layer rte.reset, rte.base, rte.theme, rte.components, rte.content`; CSS do consumidor sem camada vence **sem `!important`**.
- **R5** Aceitar `#hex`, `rgb()`, `hsl()`, `oklch()`, `color(display-p3 …)`, nomes e `var()`.
- **R6** Modos `auto` (segue o sistema, ignora o toggle do site), `inherit` (segue o `color-scheme` do `<html>`), `light`, `dark`. Documentar: "se o seu site tem tema claro/escuro, use `inherit` e declare `color-scheme` no `<html>`".
- **R7** Plano B: sem cores relativas, aplicar o resultado de `createRteTheme` (hex). Equivalência ΔE ≈ 0 nos derivados lineares, ≤ 0,019 nos neutros, ≤ 0,041 em `*-border`.
- **R8** `prefers-contrast: more` e `forced-colors` respeitados (bordas e foco reforçados; sem depender só de cor).
- **R9** `warnIfPoorTheme` (dev) avisa quando a cor escolhida não permite contraste adequado, sugerindo alternativa.
- **R10** Trocar a cor ao vivo ≤ 0,5 ms (spike: ≈ 0,2 ms).
- **R11** JS ≤ 3 kB min+gzip (ajustar após medir, registrando no ADR).
- **R12** Presets exportados: Angular (padrão), Oceano, Floresta, Pôr do sol, Monocromático.
- Valores padrão: `primary` `#8514f5`, `secondary` `#f637e3`, `tertiary` `#0546ff` (confirmar contra o press kit do Angular na Tarefa 1).
- Valores públicos de tipo: `RteTheme`, `RteThemeMode = 'auto' | 'inherit' | 'light' | 'dark'`, `neutral: 'tinted' | 'gray'`.
- CSP: variáveis aplicadas por `style.setProperty`/`CSSStyleDeclaration`, sem exigir `unsafe-inline` para atributos gerados por JS.
- Critério de aceite: 0 falhas de contraste (teste de propriedade e grade do spike) nos **3 navegadores**, ou plano B provado equivalente onde o nativo não existe.
- Herdadas da Spec 01: npm **≥ 11**; `core`/`sanitizer`/`theme` não importam `@angular/*`; `tsconfig.spec.json` com `composite: false`; novo código com teste primeiro (TDD); typecheck dos testes (`nx run theme:typecheck`); `/tmp` é um tmpfs minúsculo (use `TMPDIR=$HOME/.cache/tmp`, `NX_DAEMON=false`); mensagens de ferramentas em pt-BR, código e nomes públicos em inglês; nenhum recurso é "feito" sem teste automatizado **e** verificação em navegador real.

## Review Focus

1. **Sementes degeneradas no porte para TS** (`#000`, `#fff`, cinzas, acromáticas, matiz `NaN`, croma 0, luminância 0 ou 1): divisões por zero e `NaN` não podem vazar para o hex nem para o relatório → teste unitário em cada módulo (Tarefas 3, 5).
2. **Valor inválido nunca lança**: `createRteTheme({ primary: 'banana' })`, `''`, `'var(--x)'`, `'12px'` caem no padrão Angular (R3) e `warnIfPoorTheme` avisa; o mesmo em `applyRteTheme` (Tarefas 4, 5, 6, 7).
3. **Import em Node/SSR**: importar o pacote sem `document`/`window` não pode lançar nem ter efeito colateral; `applyRteTheme` vira no-op sem DOM (Tarefa 7).
4. **Modo em runtime**: `auto` muda quando o sistema muda (listener de `prefers-color-scheme` com *cleanup*, sem vazamento); `inherit` segue o `color-scheme` do `<html>` mesmo quando o site troca depois (Tarefas 7, 11).
5. **Acessibilidade fora do padrão**: com `forced-colors: active` e `prefers-contrast: more`, bordas e foco continuam visíveis e os tokens não colapsam na mesma cor (Tarefa 11).

```ts
export type Rgb = readonly [number, number, number];
export type Rgb8 = readonly [number, number, number];

export const clamp = (x: number, min = 0, max = 1): number => Math.min(max, Math.max(min, x));

const decode = (c: number): number => (c <= 0.04045 ? c / 12.92 : ((c + 0.055) / 1.055) ** 2.4);
const encode = (x: number): number => (x <= 0.0031308 ? 12.92 * x : 1.055 * x ** (1 / 2.4) - 0.055);

export const map3 = (v: Rgb, fn: (c: number) => number): Rgb => [fn(v[0]), fn(v[1]), fn(v[2])];

export const toLinear = (srgb: Rgb): Rgb => map3(srgb, decode);
export const toSrgb = (lin: Rgb): Rgb => map3(lin, (v) => encode(clamp(v)));
export const luminance = (lin: Rgb): number => 0.2126 * lin[0] + 0.7152 * lin[1] + 0.0722 * lin[2];
export const to8 = (srgb: Rgb): Rgb8 => map3(srgb, (v) => Math.round(clamp(v) * 255));
export const from8 = (rgb8: Rgb8): Rgb => map3(rgb8, (v) => v / 255);
export const toHex = (srgb: Rgb): string => '#' + to8(srgb).map((v) => v.toString(16).padStart(2, '0')).join('');

export function contrastRatio(a: Rgb8, b: Rgb8): number {
  const ya = luminance(toLinear(from8(a)));
  const yb = luminance(toLinear(from8(b)));
  return (Math.max(ya, yb) + 0.05) / (Math.min(ya, yb) + 0.05);
}
```

- [ ] **Step 4: Implementar `oklab.ts`**

Porte de `docs/specs/referencias/t6-tema/theme-fallback.mjs` (funções `linearToOklab`, `oklabToLinear`, `toOklch`, `fromOklch`, `oklchColor`, `mixOklch`): **mesmas constantes e mesma aritmética**, com tipos:

```ts
import { toSrgb, type Rgb } from './convert';

export type Oklab = readonly [number, number, number];
export type Oklch = readonly [number, number, number];

export function linearToOklab([r, g, b]: Rgb): Oklab {
  const l = Math.cbrt(0.4122214708 * r + 0.5363325363 * g + 0.0514459929 * b);
  const m = Math.cbrt(0.2119034982 * r + 0.6806995451 * g + 0.0883024619 * b);
  const s = Math.cbrt(0.0883024619 * r + 0.2817188376 * g + 0.6299787005 * b);
  return [
    0.2104542553 * l + 0.793617785 * m - 0.0040720468 * s,
    1.9779984951 * l - 2.428592205 * m + 0.4505937099 * s,
    0.0259040371 * l + 0.7827717662 * m - 0.808675766 * s,
  ];
}

export function oklabToLinear([L, a, b]: Oklab): Rgb {
  const l = (L + 0.3963377774 * a + 0.2158037573 * b) ** 3;
  const m = (L - 0.1055613458 * a - 0.0638541728 * b) ** 3;
  const s = (L - 0.0894841775 * a - 1.291485548 * b) ** 3;
  return [
    4.0767416621 * l - 3.3077115913 * m + 0.2309699292 * s,
    -1.2684380046 * l + 2.6097574011 * m - 0.3413193965 * s,
    -0.0041960863 * l - 0.7034186147 * m + 1.707614701 * s,
  ];
}

export function toOklch(lin: Rgb): Oklch {
  const [L, a, b] = linearToOklab(lin);
  return [L, Math.hypot(a, b), ((Math.atan2(b, a) * 180) / Math.PI + 360) % 360];
}

export function fromOklch([L, C, h]: Oklch): Rgb {
  const rad = (h * Math.PI) / 180;
  return oklabToLinear([L, C * Math.cos(rad), C * Math.sin(rad)]);
}

export const oklchToSrgb = (L: number, C: number, h: number): Rgb => toSrgb(fromOklch([L, C, h]));

/** color-mix(in oklch, a pA%, b): interpola L, C e H (arco curto); matiz de cor acromática é "ausente". */
export function mixOklch(a: Oklch, pA: number, b: Oklch): Oklch {
  const [La, Ca, ha] = a;
  const [Lb, Cb, hb] = b;
  const t = 1 - pA;
  const achromaticA = Ca < 1e-4;
  const achromaticB = Cb < 1e-4;
  let h: number;
  if (achromaticA && achromaticB) h = 0;
  else if (achromaticA) h = hb;
  else if (achromaticB) h = ha;
  else {
    let d = hb - ha;
    if (d > 180) d -= 360;
    if (d < -180) d += 360;
    h = (ha + d * t + 360) % 360;
  }
  return [La * pA + Lb * t, Ca * pA + Cb * t, h];
}
```

```ts
import { clamp, luminance, toSrgb, type Rgb } from './color/convert';
import { fromOklch, mixOklch, toOklch, type Oklch } from './color/oklab';

const WHITE_Y = 0.1791;

export interface DerivedRole { seed: Rgb; on: Rgb; hover: Rgb; active: Rgb; text: Rgb; subtle: Rgb; border: Rgb }

export function deriveRole(seedLin: Rgb, surface: Oklch, dark: boolean): DerivedRole {
  const y = luminance(seedLin);
  const s = clamp((WHITE_Y - y) * 1000); // 1 = semente escura (texto branco), 0 = clara (texto preto)
  const state = (amt: number): Rgb =>
    [0, 1, 2].map((i) => {
      const c = seedLin[i] as number;
      return c * (1 - amt * s) + amt * (1 - s) * (1 - c);
    }) as unknown as Rgb;
  const text: Rgb = dark
    ? ([0, 1, 2].map((i) => { const c = seedLin[i] as number; return c + (1 - c) * clamp((0.28 - y) / (1 - y)); }) as unknown as Rgb)
    : ([0, 1, 2].map((i) => (seedLin[i] as number) * Math.min(1, 0.13 / y)) as unknown as Rgb);
  const seedOk = toOklch(seedLin);
  return {
    seed: toSrgb(seedLin),
    on: toSrgb([s, s, s]),
    hover: toSrgb(state(0.14)),
    active: toSrgb(state(0.26)),
    text: toSrgb(text),
    subtle: toSrgb(fromOklch(mixOklch(seedOk, 0.12, surface))),
    border: toSrgb(fromOklch(mixOklch(seedOk, 0.45, surface))),
  };
}
```
